Guia Rápido para Usar o Style Cut

Bem-vindo ao sistema mais moderno de agendamento para salões!

Cadastre e gerencie seus clientes:
  • Insira nome e telefone
  • Clique em "Adicionar Cliente"
  • Use os botões de editar/excluir na lista

Agende serviços facilmente:
  • Selecione cliente, colaborador e serviço
  • Escolha data e hora
  • Valor é calculado automaticamente
Dicas Importantes
  • Dados são salvos automaticamente
  • Use o tema escuro para reduzir o cansaço visual
  • Clientes com agendamentos não podem ser excluídos
  • Certifique-se de que a data seja futura
